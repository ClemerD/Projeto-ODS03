# 🌱 Projeto ODS 3 — Saúde e Bem-Estar

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um trabalho acadêmico relacionado aos **Objetivos de Desenvolvimento Sustentável (ODS)** da Organização das Nações Unidas (ONU).

O projeto está relacionado ao **ODS 3 — Saúde e Bem-Estar**, que busca assegurar uma vida saudável e promover o bem-estar para todas as pessoas, em todas as idades.

A página apresenta informações e conteúdos educativos relacionados à **prevenção da mortalidade infantil no Brasil**, destacando a importância da prevenção, do acompanhamento durante a gestação e dos cuidados com a saúde materno-infantil.

---

## 🎯 Objetivo

O objetivo do projeto é apresentar informações de forma simples e acessível, contribuindo para a conscientização sobre fatores relacionados à mortalidade infantil e sobre a importância da prevenção e do acompanhamento adequado da saúde.

A página também apresenta dados comparativos entre as diferentes regiões do Brasil.

---

## 📊 Conteúdo

Entre os principais conteúdos apresentados estão:

* Informações sobre o ODS 3;
* Dados sobre mortalidade infantil no Brasil;
* Comparação entre as regiões brasileiras;

## 📈 Gráfico de mortalidade infantil

O projeto apresenta um gráfico comparativo com indicadores de óbitos por mil nascidos vivos entre as regiões brasileiras.

Os dados apresentados na página são referentes a **2024**, tendo como referência dados do Ministério da Saúde (SIM/SUS) e a publicação da Fundação Abrinq.

O gráfico possui animação para tornar a apresentação dos dados mais visual e facilitar a comparação entre as regiões.
